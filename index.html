Mode Tamu (Offline Lokal) ⚙️ Setup Supabase Pribadi

☁️ Pengaturan Supabase Cloud

Hubungkan aplikasi GoalGetten ke proyek Supabase PostgreSQL Anda agar seluruh data tersinkronisasi otomatis di laptop, HP, dan tablet.

Ditemukan di Dashboard Supabase > Project Settings > API > Project URL.
Ditemukan di Dashboard Supabase > Project Settings > API > Project API keys > anon public.
💡 Langkah Singkat Setup Supabase:
  1. Buka supabase.com dan buat akun / proyek baru gratis.
  2. Buka menu SQL Editor dan jalankan skrip dari berkas schema.sql.
  3. Salin URL & Anon Key proyek ke form di atas, lalu klik Simpan & Hubungkan.
